Embeddable Website Widget

This page demonstrates the public widget prototype. Configure the company slug and API base URL below.

Embed snippet

<div
  id="ai-agent-widget"
  data-company-slug="your-company-slug"
  data-api-base="https://api.example.com"
  data-title="Chat with us"
></div>
<script src="https://api.example.com/static/widget/widget.js"></script>
